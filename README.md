# Pipeline – Growth & Partnerships

Mobile-first PWA for Rakesh's staffing sales pipeline. Reads and writes the SharePoint workbook
"Sales Pipeline - Growth & Partnerships.xlsx" through Microsoft Graph (Excel API), works offline
with a write queue, and polls the sheet every 20 s for changes made in Excel.

- Setup: see SETUP.md
- Only file to edit: js/config.js
- Demo with sample data: open index.html?demo=1
